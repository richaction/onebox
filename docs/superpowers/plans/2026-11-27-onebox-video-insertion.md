# Onebox 视频插入与本地归档计划

## 目标

在正文中插入普通超链接或视频。视频可从本地文件导入，也可在线解析后下载。导入完成后，视频保存在 Markdown 同级的 `assets/`，正文插入可离线播放的视频块。下载、校验和文件落盘由 Onebox 的 Tauri/Rust 后端在本机完成。

周末先交付本地视频的完整流程。HTTPS 视频直链接在同一条导入链路上，平台链接按授权样本的实测结果逐个开放。

## 插入入口

- [ ] **`/超链接`**打开地址和显示文字输入框。优先用选区文字作为标题，未填写标题时显示链接地址。复用现有链接校验，写成标准 Markdown 链接。
- [ ] **`/视频`**打开两个选项。
  - **本地文件**打开文件选择器，复用拖放导入流程。
  - **在线解析**接收视频直链或平台分享链接。提交后启动解析和下载任务。失败时可重试，也可用同一个超链接流程插入原始链接。

[现有链接交互](../../../src/ui/SelectionToolbar.tsx) · [斜杠菜单](../../../src/ui/EditorShell.tsx)

## 1. 本地视频与文档

- [ ] 从「本地文件」或拖放导入视频。文档尚未保存时，先使用现有保存流程确定附件目录。
- [ ] 首版以 MP4（H.264 + AAC）为兼容目标。视频块点击播放，支持暂停、跳播和全屏。缺失文件或格式无法播放时，保留文件链接并给出原因。
- [ ] 视频首帧加载慢时，在播放器内延迟显示「正在加载视频…」。播放或跳播遇到等待时显示「正在缓冲…」，可继续播放时清除提示。读取失败时切换到错误状态，保留「重试」和「打开文件」入口。
- [ ] 复用已有附件导入逻辑。流式读取文件，按内容哈希生成文件名，在 `assets/` 原子落盘。重复导入同一文件时复用已有副本。
- [ ] Markdown 保存普通相对链接，紧邻链接的 Onebox 标记用来恢复播放器。标题保留在链接文本中。其他 Markdown 编辑器可按普通链接打开视频。同步覆盖前端 Markdown 解析、序列化及 Rust 大文档解析路径。
- [ ] 复用已有本地资源授权，按文件开放播放。验证 macOS WKWebView 上大文件的 Range 请求和跳播。前端通过资源 URL 播放，避免把整个视频读入内存再经 IPC 传输。
- [ ] 接入文档移动和另存为的附件处理。重新打开时恢复播放器，撤销插入时移除文档引用。附件的删除沿用现有管理方式，避免影响其他文档的共享引用。

## 2. HTTPS 视频直链

- [ ] 「在线解析」识别 HTTPS 视频直链后，交给 Rust 流式下载。Rust 校验协议、访问范围和每次重定向，检查剩余磁盘空间，并限制下载大小和超时。
- [ ] 任务显示下载、校验、保存、完成或失败状态。收到总长度时显示进度，否则显示已下载大小。支持取消和手动重试，失败或取消时清理临时文件。校验媒体后再提交到 `assets/`。
- [ ] 每个任务绑定原文档和可随编辑移动的插入位置。切换文档后，结果继续属于原文档。原文档已关闭、被改名或插入位置失效时，显示「已下载，待插入」，由用户选择位置。
- [ ] 无法获取文件时，显示可操作的原因，例如断网、链接过期或格式不兼容，并提供「插入原始链接」。

## 3. 平台链接与批量队列

平台解析器返回媒体、来源和失败原因，附件落盘与正文插入继续走同一路径。优先评估 `yt-dlp` 和 FFmpeg，使用用户已安装的版本或首次启用时安装并校验版本。解析器独立更新，便于应对平台变更，也能控制主安装包体积。

| 来源 | 接入条件与回退 |
| --- | --- |
| 抖音 | 用允许下载的样本分别验证分享短链和作品链接。遇到不可下载、链接失效或验证要求时，保留原始链接。 |
| X | 用允许下载的帖子验证单视频导入。官方下载只适用于部分符合条件的帖子，作者可关闭下载。 |
| YouTube | 默认保存原始链接。用户已有的授权文件走本地导入。自动归档作为独立评估项，先核对下载与离线保存的适用条件。 |
| 更多站点 | 逐个验证授权样本、成功路径和失败回退，通过后再加入支持列表。 |

- [ ] 解析器运行在独立进程中，由 Onebox 管理工作目录、超时和取消。视频需要合并音轨或转换时，后台调用 FFmpeg，完成后再进入附件导入。
- [ ] 单条链路稳定后，支持一次粘贴多条链接。队列限制并发，同一批中可以取消单个任务或重试失败项，每条链接依次回填到提交时指定的位置。

[yt-dlp 支持站点](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) · [解析与合并工具依赖](https://github.com/yt-dlp/yt-dlp#dependencies) · [抖音授权视频数据](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/server/basic-abilities/video-id-convert/user-video-data/) · [X 视频帮助](https://help.x.com/en/using-x/x-videos) · [YouTube 服务条款](https://www.youtube.com/t/terms) · [YouTube 开发者政策](https://developers.google.com/youtube/terms/developer-policies)

## 周末开发顺序

1. 先做一个桌面验证样例。用本地大 MP4 验证文件授权、播放和跳播，确定播放器的基本链路。
2. 接入 `/超链接`、`/视频 → 本地文件` 和拖放，完成附件导入、Markdown 往返和视频块。
3. 验证自动保存、移动、另存为、撤销和缺失附件。通过后接入 `/视频 → 在线解析` 的 HTTPS 直链任务。
4. 用可下载样本实测抖音和 X，记录支持的链接形式与失败提示，再决定批量和更多站点的顺序。

## 验收清单

- [ ] `/超链接` 提交视频平台地址时生成普通 Markdown 链接。通过 `/视频` 选择「本地文件」进入文件选择器，选择「在线解析」进入链接输入和任务流程。
- [ ] 同一视频导入两次，`assets/` 只有一份对应的视频文件。
- [ ] 断网、关闭并重新打开文档后，大视频可以播放并跳到未播位置。
- [ ] 大视频首帧慢或跳播后缓冲时，提示出现在播放器内，正文仍可编辑。播放就绪后提示自动消失，读取失败时显示错误和重试入口。
- [ ] 将文档另存为或移动到另一目录，目标文档里的视频可播放，原有共享引用仍有效。
- [ ] 普通 Markdown 编辑器能打开相对视频链接，普通视频文件附件的现有显示方式仍可用。
- [ ] 下载期间编辑或切换文档，结果回到原文档或进入「待插入」。取消和失败后没有半成品文件或失效的正文引用。
- [ ] 平台链接失败时能保存原始链接。主包与平台工具分别记录实际体积。
