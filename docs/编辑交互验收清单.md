# Onebox 编辑交互验收清单

以桌面 Notion 的编辑操作为参考，用相同的输入和结果验收 Onebox。左侧双击选块、选块时隐藏文字浮动栏是 Onebox 的交互约定。每一行都可以用独立的 Markdown 样例复测。

## 先验收选择和菜单

| 编号 | 操作 | 通过条件 | 进度 |
| --- | --- | --- | --- |
| S01 | 从文字内部拖选，跨过段落或列表项 | 只选中经过的文字，列表标记和复选框不进入文字选区。松手后出现文字浮动工具栏 | 已有，保留 |
| S02 | 从页面左侧或右侧空白处按住并拖动 | 高亮路径上的完整区块。向上和向下均可选择。开始拖动前的轻微位移不选整块 | 本次实现 |
| S03 | 双击区块左侧空白处 | 只选中对应区块。单击只放置光标。两块之间选视觉上更近的那一块 | 本次实现 |
| S04 | 在待办列表边缘拖选 | 同一级列表内按完整行高亮。拖出该列表、跨到其他文档区块时，按完整顶层区块高亮 | 本次实现 |
| S05 | 选中一个或多个区块后移动鼠标或松手 | 保留区块高亮，不自动打开文字浮动工具栏。正文右键和区块拖柄的显式菜单仍可打开 | 本次实现 |
| S06 | 点击正文、按 Esc 或在选块后按 Enter | 点击正文回到点击处。Esc 退出选块。Enter 进入选区内第一处可编辑文字 | 本次实现 |
| S07 | 拖选时靠近视口上沿或下沿 | 页面沿拖动方向滚动，范围随鼠标继续延伸。松手后结束滚动并保留选区 | 本次实现 |
| S08 | 连续点粗体、斜体与 AI 编辑 | 每次点击只作用于本次目标。触控板小幅位移、按下和松开事件乱序时也能逐次响应 | 已有回归测试，继续纳入验收 |
| S09 | 使用方向键、Shift 方向键和 Shift 点击 | 可移动选区块，或从固定起点扩展和收回范围。跨过列表、表格和不可编辑块时规则一致 | 待实现 |
| S10 | 使用 Cmd/Ctrl+A 和修饰键点选 | 验收单块到全篇的选择层级，以及添加或移除不连续区块 | 待实现 |

## 再验收输入、区块命令和移动

| 编号 | 操作 | 通过条件 | 进度 |
| --- | --- | --- | --- |
| E01 | 在段落中间、标题末尾、列表和代码块中按 Enter 或 Shift+Enter | 分块、续行或软换行符合各区块预期，光标落在正确位置，撤销一步回到原状态 | 逐类型对照 |
| E02 | 在空列表项按 Enter，在块首按 Backspace 或 Delete | 正确退出列表、处理缩进和合并相邻块，任务状态与格式按明确规则保留 | 逐类型对照 |
| E03 | 中文输入法连续组词，然后按 Enter、Esc 或方向键 | 先由输入法确认或取消组词，菜单快捷键只在组词结束后接管 | 逐场景对照 |
| E04 | 输入 `/`、键入关键词、用方向键或鼠标选项 | 菜单定位靠近光标，过滤结果和键盘高亮一致。Esc 关闭，执行后只清除本次命令文本 | 已有基础，逐项对照 |
| E05 | 使用行首 Markdown 快捷输入 | 标题、项目符号、编号、待办和引用按各自触发规则转换。普通正文中的相同字符保留 | 已有基础，逐项对照 |
| E06 | 悬停在区块边缘，点击插入入口或操作拖柄 | 边缘入口与所在块对齐。插入位置明确。点按、拖动和菜单操作各有独立结果 | 已有选中区块拖柄，待补悬停入口 |
| E07 | 拖动单个区块和多个选中区块 | 插入线明确，移入列表等兼容位置时保持顺序和结构。无效目标取消。一次撤销回到原位置 | 已有单块拖动，多块待实现 |
| E08 | 对整块复制、剪切、删除和复制副本 | 复制保留 Markdown 结构，删除和剪切可撤销。跨列表和跨长文档分组时内容一致 | 基础待逐项验证，批量复制副本待实现 |
| E09 | 用键盘打开区块命令或从右键转换区块 | 执行前明确作用范围。菜单里的插入、转换、复制和删除与实际选区一致 | 已有显式菜单，待验收多块命令 |
| E10 | 在表格、代码块、媒体和公式之间编辑 | 文字、单元格和整块选择各有明确手势。键盘导航、复制和退出编辑可逐类复测 | 按区块类型对照 |
| E11 | 输入或粘贴 Markdown、链接、富文本和图片 | 粘贴保留 Onebox 支持的结构。关注内部复制、外部粘贴、换行和剪贴板撤销四条路径 | 已有基础，逐项对照 |
| E12 | 从文字工具栏发起 AI 编辑 | 输入框紧贴选区并可直接输入。关闭、取消或应用建议后正确恢复或更新原选区 | 已有基础，继续验收 |

## 每轮复测

- 最小样例包含两段正文、一个标题、三条待办和一个表格，再加入长文档测试跨屏和跨分组。
- 检查落点、选区、焦点以及最终 Markdown。选择、打开菜单和取消操作时逐字节核对原文。
- 桌面上分别复测鼠标、触控板轻点和中文输入法。记录实际输入方式和测试结果，避免用模拟点击替代硬件验证结论。
