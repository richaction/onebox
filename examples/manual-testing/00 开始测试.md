# Onebox 人工测试

这里是独立的样例工作区。可以直接编辑、拖动和新建文件。更改会保存在此副本中。

| 目录 | 可以验证 |
| --- | --- |
| 01 编辑器 | 中英文排版、区块菜单、代码语言、宽表格、脚注、只读保护 |
| 02 性能 | 十万和百万字符、长段落、跨屏选择、保存和撤销 |
| 03 附件移动 | 文件夹和 Markdown 移动、重名且同内容的附件、跨目录链接 |
| 04 文件预览 | PDF、Word、Excel、PowerPoint、图片、音视频与不同编码的文本 |

## 编辑与样式

- [ ] 在空行输入 `/`，用方向键搜索并插入表格或代码块。
- [ ] 在正文右键转换区块，输入三个井号加空格创建三级标题。
- [ ] 修改代码语言，检查 Java、Python、Shell 与无语言模式。
- [ ] 缩窄窗口，横向滚动宽表格，并在靠右的单元格中编辑。
- [ ] 切换到另一个文件，再打开原文件核对自动保存。

## 文件和附件

- [ ] 在「03 附件移动」里把「移动我.md」拖到「目标」。
- [ ] 打开移动后的文档，检查图片、同目录链接及指向它的外部链接。
- [ ] 检查目标中同内容的图片被复用，两个同名异内容的文本都能访问。
- [ ] 在测试文档中粘贴、拖放或从区块菜单插入附件。
- [ ] 新建一个目录和 Markdown 文件后，再测试复制与重命名。

## 预览和性能

- [ ] 打开「Excel 冻结窗格与两万行.xlsx」，检查默认工作表中的合并单元格、图表、深处滚动和工作表切换。
- [ ] 测试冻结窗格兼容性，切换工作表后检查标签和滚动。
- [ ] 打开 Word 或 PowerPoint，验证右侧直接显示分页预览。
- [ ] 用图片工具栏或触控板缩放，放大后拖动图片并恢复适合窗口。
- [ ] 打开多页 PDF，检查目录、翻页、缩放和连续滚动。
- [ ] 播放音视频，拖动进度条到末尾并重新播放。
- [ ] 在百万字符样例前、中、后输入、粘贴、撤销，确认滚动与保存正常。
